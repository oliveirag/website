# The website departs from the design system on colour, type and sound

My design system is achromatic, allows two typefaces and forbids custom sounds. The website breaks all three on purpose, because it is the one place meant to feel like being outdoors: the Intro and the Field carry colour, Instrument Serif is used for my name and page titles, and the site plays an Ambience and Cues.

The departure is contained. Cards, buttons, borders and body text still read the design system tokens and stay achromatic in JetBrains Mono. Nothing here flows back into the design system or into other projects.

Thoughts posts are the one place where body text leaves JetBrains Mono: a post, and each entry on the Thoughts list, reads in a serif, Source Serif 4, so a post reads like a page in a book. It stays achromatic in the design system's greys, its code stays in JetBrains Mono, and only the Thoughts pages load it.
