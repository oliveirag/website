# The Designely files are kept apart and are not MIT

The Intro and the Field are exports from Designely Studio, whose licence lets me ship and edit the components but forbids changing the runtime, removing its notices, or sharing the components as components. This repository is public and MIT, so the Designely files live in one folder with their notices intact, the runtime file is never edited, and `LICENSE` and the README say that folder is excluded from MIT.

Colour and scene changes go through the component files and their settings, never through the runtime. The production bundle must still carry the runtime's copyright notice.
